Computer Vision

Dimension X: Logistics AI

Fully autonomous logistics platform calculating box dimensions and packing capacity using a custom YOLOv8 model.

Python YOLOv8 OpenCV Flask

Dimension X is a fully autonomous, computer-vision-based logistics platform designed to replace inaccurate manual measurements with high-precision AI calculations. It calculates physical dimensions, optimizes packing capacity, and performs intelligent weight-splitting in real-time.

Technical Architecture

  • Custom YOLOv8: Uses advanced CNNs to accurately detect boundaries and corners of boxes, even when partially obscured.
  • ArUco Marker Calibration: Establishes a precise pixel-to-metric ratio.
  • Multi-Modal API Integration: Integrates Cloud Vision APIs (LLaVA / Gemini) to identify the contents of the boxes semantically.

Use Cases: Warehousing & Fulfillment Centers, Courier & Postal Services, Smart Manufacturing, and Agricultural Logistics.
